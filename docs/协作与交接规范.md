# 协作与交接规范

## 使用同一套画面

- 画幅1080×2376，手机竖屏；30fps。参考图可按比例适配，不拉伸主体。
- 主色清华紫 `#660099`，浅紫和白色卡片；沿用参考图的圆角、文字层级、图标和边距。
- 时间19:11。时间旁不出现应用广告图标，客服图标不出现88VIP。
- 底部导航：首页、直播、消息、选课车、我的课表。只高亮当前所在页面。
- 账号为小五同学，使用仓库头像；课程图片尽量复用，避免同一课程在不同段换封面。
- 不添加手机外框、实拍手或桌面鼠标；操作提示如需出现，三段使用同一形式。
- 字体和图标最终选型尚未锁定。第一段确定后在 shared 中登记并同步，中文字体须实际可用，提交工程时说明依赖。

## 第一段与第二段

按最新版v2中“这部分直接从列表开始做，不用做点卡片的动画”的标注执行：第一段做到主播下方课程卡出现，第二段直接从商品列表开始。两段以课程卡→商品列表的直接切换衔接，不额外制作点击卡片或列表上滑的过渡动画。

第一人提交课程卡出现后的尾帧 `assets/handoff/live-card-end.png`，第二人制作商品列表首帧 `assets/handoff/product-list.png`，内容就是去掉开屏过程的首页课程列表。两张图中花卉鉴赏的名称、2学分、封面及加购状态须一致，由两人共同确认。

角标初值在开工时统一，建议5，随后加5门到10。课程清单和学分登记在 shared/course-state.json；没有确定前不要各自填一组正式数字。

交接图尚未完成时，双方可按约定布局制作可替换占位画面；交付时使用已确认版本。第一段末尾和第二段开头各留一点静止余量，方便总剪。

## 第二段与第三段

交接点为完全黑屏。

第三人先制作同一张锁屏壁纸和10月22日锁屏图，放入 `assets/handoff/`。第二段支付成功后使用这张图，熄屏并结束。第三段从黑屏中的通知声开始，11月2日亮屏，最后回到同一张10月22日锁屏。

第三段自行负责通知卡展开进入订单的转场，以及退款失败后熄屏、回到原日锁屏的转场，不拆给其他人。

## 声音与总剪

各段保留主播声音和必要操作/通知/支付/扣款音，并提供音轨说明；音乐由总剪统一加入。第一、二段如需持续的主播小窗声音，共享同一个源音轨，记录交接位置，不各自录制不连续的对白。

总剪检查三段画幅、导航、课程封面和数字连续性，再调整整体时长与配乐。不平均分秒数，不用补无关信息凑时长。需要缩短时优先减少重复浏览和重复扣款。

## 提交与评审

从main创建自己的work分支→在自己目录制作→提交阶段成果→发起PR→检查交接图和未完成项→由项目负责人合并。共享文件的修改在PR中明确列出，由涉及段落的负责人一起确认。

这里约定的是团队流程；尚未设置GitHub分支保护或自动合并限制。
