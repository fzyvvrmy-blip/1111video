## 可编辑源文件

- `animation.template.html`：页面结构、图标、样式、确定性动画与播放控件。
- `preview-state.json`：十门课程、学分、预估睡眠和加购顺序。
- `build_preview.py`：从相对路径读取参考图、生成矢量封面与操作音，打包独立HTML。
- `render_preview.cjs`：逐帧导出H.264/AAC视频；支持单独导出关键帧。
- `inspect_preview.py`：读取实际编码的视频，核对画幅、帧率、时长和纯黑尾帧，生成审阅图。
- `keyframes/preview-v4/`：新版关键首尾帧、加购、十门同屏、费用与先用后付、锁屏及审阅图。`mobile-review.jpg`按270像素宽检查手机尺寸下的可读性；`payment-transition.jpg`展示数字移动与倒数的实际编码画面。

所有素材内容和项目路径均相对于本目录或仓库根目录。渲染工具的实际安装位置由命令行参数传入。

## 运行与导出

Python依赖：Pillow、NumPy；编码检查还需OpenCV。渲染依赖Node、Playwright、Chromium兼容浏览器及带libx264的FFmpeg。当前视频使用系统已安装的工具，未新增项目依赖。

中文字体为当前机器实际可用的Microsoft YaHei；HTML提供PingFang SC、Noto Sans CJK SC后备。最终合片前需与第一、三段统一字体。

从本目录执行，替换各工具路径：

```text
python build_preview.py --ffmpeg <FFmpeg可执行文件>
node render_preview.cjs <Playwright模块目录> <浏览器可执行文件> <FFmpeg可执行文件>
python inspect_preview.py
```

末尾追加 `stills` 参数只输出关键帧，并检查初始空车、10门同时可见、必修/选修各5门、无滚动和门槛文案已删除，同时检查上方18→中间数值→0、下方签收后消耗18小时及主按钮尺寸。视频和独立操作音写入被Git忽略的`renders/`，关键帧正常保留。当前视频名为`renders/part02-preview-v4.mp4`；旧版视频与HTML副本仍在`renders/`中，方便比较。
