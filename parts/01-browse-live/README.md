本工程制作开屏、首页浏览、直播小窗展开与课程卡弹出。当前v2为18.5秒的可播放预览，新增横滑广告、快速浏览、集市书摊老板及临时喇叭质感合成配音。老板使用两张匹配关键画面，没有连续人物动作或口型。

- 开屏文字上移，首页显出；横幅三张广告横向滑动，带页码点。
- 商品列表12门，包含两次快速上划、惯性减速和停顿；新增课程与学分为画面占位，尚未按真实课程目录确认。

- 花卉鉴赏课程卡从底部弹出，最后两秒留交接余量。
- 选课车角标为5，和第二段建议的起始数量一致。
- 临时配音来自本机Windows康康合成声音，再做喇叭滤波；保留界面提示音，无背景音乐或人物内心字幕。

## 运行

需要Node.js、`@napi-rs/canvas` 0.1.100与可用的FFmpeg。依赖声明在package.json中。标准Node环境先安装声明的依赖，再执行：

```text
npm run render
```

FFmpeg不在系统路径时，用环境变量 `FFMPEG_PATH` 指定其可执行文件。Windows临时声音生成脚本为 `make-voice.ps1`；非Windows环境直接复用已提交的audio文件。此桌面环境使用了已有依赖、FFmpeg及声音，无需另装渲染软件。

```text
npm run frames
node render.mjs --half
```

前者只导出关键帧；后者生成540×1188的小尺寸预览。完整输出位于 `exports/part-01-interface-preview-v2.mp4`；审阅副本在 `previews/`，随本轮工程一起同步GitHub。`scene.json` 可调整广告词、课程、手势节奏、弹窗速度、声音和画幅。

中文字体当前使用Windows微软雅黑；其他系统可通过 `FONT_REGULAR` 和 `FONT_BOLD` 指定可用中文字体的文件路径，避免缺字。字体文件未打包或上传。
