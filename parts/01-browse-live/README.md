# 第一段界面动效预览

本工程制作开屏、首页浏览、直播小窗展开与课程卡弹出。当前版本是18.5秒的可播放界面动效预览，不是带真人口型、手势和配音的最终直播成片。

## 当前内容

- 1080×2376、30fps。
- 开屏文字上移，首页显出；商品区域滚动，状态栏和底部导航固定。
- 主播小窗从右上角展开；小窗和全屏来自同一个画面，位置和裁切连续变化。
- 花卉鉴赏课程卡从底部弹出，最后两秒留交接余量。
- 选课车角标为5，和第二段建议的起始数量一致。
- 只有合成的界面提示音，无背景音乐、主播配音和人物内心字幕。

## 主播素材的真实状态

`assets/presenter-static.png` 是从已确认的直播v2参考图清理界面后生成的静态底图。镜头只有极轻的推拉，主播没有口型、举书或指向下方的动作。需要接入动态素材后，才能把这一版升级为正式主播视频。

后续替换素材需保留同一学长形象、服装和花卉鉴赏教材；动画的小窗和全屏应共用同一时间轴。当前 `livePage()` 中的静态底图绘制是待替换点，不能把它称作已经完成的人物动画。

## 运行

需要Node.js、`@napi-rs/canvas` 0.1.100与可用的FFmpeg。依赖声明在package.json中。标准Node环境先安装声明的依赖，再执行：

```text
npm run render
```

FFmpeg不在系统路径时，用环境变量 `FFMPEG_PATH` 指定其可执行文件。此桌面环境使用了已经存在的依赖和FFmpeg，没有另装渲染软件。

```text
npm run frames
node render.mjs --half
```

前者只导出关键帧；后者生成540×1188的小尺寸预览。完整输出位于 `exports/part-01-interface-preview-v1.mp4`；源文件和交接尾帧使用相对路径。`scene.json` 可调整节奏、画幅、角标及参考图裁切区域。

中文字体当前使用Windows微软雅黑；其他系统可通过 `FONT_REGULAR` 和 `FONT_BOLD` 指定可用中文字体的文件路径，避免缺字。字体文件未打包或上传。
