## 人物与声音

三十岁左右的老板已通过HeyGen网页制作成人物视频。原片有连续的嘴部、头部、肩膀和手臂活动。v6使用两张人物参考图，移除旧康康合成干声，由模型同时生成新中文对白与说话表演；生成记录见assets/bookseller-motion-v2-job.json。旧片与旧音频保留对照。

原片15.167秒、768×1344、24fps；手机界面合成为1080×2376、30fps，人物按比例裁切适配，保持原速。当前使用源片0–15秒，台词只说一遍，课程卡在20.05秒随“上链接”出现。较v5增加的时长用于新的“号外号外！双十一学分大甩卖！”开场。

小窗和全屏读取同一视频帧，展开不重播。尾部界面停稳后，人物仍继续活动。成片使用人物视频原声，图像和音轨使用相同起点与裁切；80Hz高通、7000Hz低通保留男声共鸣，不改变音高、速度或时长。逐字口型和声音观感需观看反馈。

scene.json的presenterVideo控制文件、开始时间、源片裁切和原声开关。已配置的视频缺失时直接报错；移除该字段才能进入旧版的静态图片绘制分支，避免把静态方案当作新版交付。

## 可编辑工程与渲染

render.mjs绘制界面；presenter-video.mjs通过FFmpeg流式逐帧读取人物视频。广告、课程、浏览节奏、弹窗与整体时长在scene.json中调整。人物素材已下载，重新渲染不需要平台登录或再次生成。

初始选课车为0，与用户认可的第二段v4保持一致。新增课程及学分仍属于预览数据。三段课程封面、图标及公共交接图待总剪统一。

依赖Node.js、@napi-rs/canvas 0.1.100与FFmpeg；依赖声明在package.json。标准Node环境先安装依赖，再执行：

```text
npm run render
npm run frames
node render.mjs --half
```

完整输出在exports，审阅副本在previews。FFmpeg不在路径时设置FFMPEG_PATH；可通过CANVAS_MODULE_ROOT指定canvas模块根目录。字体默认微软雅黑，其他系统可用FONT_REGULAR和FONT_BOLD指定可用字体。

previews中的人物原片、合成视频、必要素材和生成记录随工程同步GitHub。缓存、模型、临时关键帧和依赖不上传。当前工作分支work/part-01，不自动合并main。
