# 双十一选课短片

把双十一购物和选课、期中考、P/F结合起来的手机录屏短片。目标约一分钟，按画面自然调整节奏。

## 从这里开始

1. 阅读 [最新版大纲](docs/大纲v2.md)，原始 Word 同步保存在 `docs/大纲v2.docx`。
2. 阅读 [协作与交接规范](docs/协作与交接规范.md)；已有参考图在 [assets/references](assets/references/README.md)。
3. 认领下面一个任务，在自己的分支制作。需要变更公共素材，先在合并请求中说明。

| 负责人 | 任务 | 建议分支 | 工作目录 |
| --- | --- | --- | --- |
| 第一人 | [浏览与直播种草](tasks/01-浏览与直播.md) | `work/part-01` | `parts/01-browse-live/` |
| 第二人 | [加购与支付](tasks/02-加购与支付.md) | `work/part-02` | `parts/02-cart-payment/` |
| 第三人 | [期中签收与结尾](tasks/03-期中与结尾.md) | `work/part-03` | `parts/03-midterm-ending/` |

`main` 放已确认内容，每个人从最新 `main` 创建自己的分支。完成阶段成果后发起合并请求，由总剪负责人检查，再合入 `main`。不要求每人各做20秒。

## 给各自 Codex 的开工说明

打开这个仓库，让 Codex 先读 `AGENTS.md`、`docs/协作与交接规范.md`，再读取自己对应的 `tasks/` 文件，按文件中的素材和边界开始工作。先确认当前环境具备所需的画面、声音和视频输出能力；遇到不具备的能力如实说明，保留已经完成的素材与工程。

## 文件说明

- `docs/`：大纲和共同规范。
- `assets/references/`：已确认的视觉参考，仅保留应使用的版本。
- `assets/handoff/`：共同交接画面，先约定再使用。
- `shared/`：统一画面参数与待确认项。
- `tasks/`：三人的任务说明。
- `parts/`：各自的源文件、素材和交付记录。
- `deliveries/`：最终视频的版本和链接记录。

用户要求每轮对话结束前自动同步本项目工程到GitHub。源文件、必要素材、关键首尾帧、制作说明和各段 `previews/` 中的小型审阅视频一并提交到对应工作分支；依赖和临时渲染缓存仍忽略。更大的视频交付文件另用共享链接，记在各段 `DELIVERY.md`。工作分支不会自动合入main。
