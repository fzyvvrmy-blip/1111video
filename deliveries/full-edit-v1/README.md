## 重建

需要Python 3（numpy、Pillow）、Node.js、@napi-rs/canvas、Playwright与Chromium，以及FFmpeg。使用Microsoft YaHei重建第一、二段和数字覆盖层；第三段原片字体保留作者的Noto Sans CJK SC，未宣称全片字体已经逐像素统一。设置FFMPEG_PATH，或把FFmpeg加入路径。

1. 在source/part01运行`node render.mjs`。它引用仓库内第一段人物源片与公共首页素材。
2. 运行`python prepare-part02.py`，然后在source/part02运行`node render_preview.cjs <Playwright模块路径> <Chromium路径> <FFmpeg路径>`。总剪以已经修改的独立part02-preview.html为准；原build_preview.py只用于重建同版音效，不要用其main覆盖独立页面。
3. 运行`node patch-part03.mjs`，保留第三段原视频并生成独立衔接修正版。
4. 运行`python assemble.py`。完整预览保存在previews/double11-full-edit-v1.mp4。

exports、renders及临时帧不上传；必要源片、独立HTML、可编辑场景、覆盖层、配音素材引用、时间表和总片随本分支同步。
