## 源文件和输出

- `animation.template.html`：页面结构、样式、图标、动画和播放控件。
- `preview-state.json`：课程、学分、睡眠消耗及加购顺序。
- `build_preview.py`：打包本地封面、矢量图和操作音，生成独立HTML。
- `render_preview.cjs`：导出视频和关键帧，核对课程合计、名称截断、占位内容和先用后付数字连续性。
- `inspect_preview.py`：解码实际视频，核对尺寸、帧率、时长、纯黑尾帧，生成审阅图。
- `renders/part02-preview-v6.mp4`：当前视频。历史视频保留在`renders/`中。
- `renders/operations.wav`：独立操作音；视频内合入立体声音轨。
- `keyframes/preview-v6/`：首尾帧、关键页面、`overview.jpg`、`mobile-review.jpg`和`payment-transition.jpg`。

首页横幅、微积分、大学物理、花卉鉴赏封面复用仓库参考图。花卉鉴赏保持2学分、早八精品；其余新增封面为内嵌SVG，电工与电子技术采用电路图案。

## 运行与导出

Python依赖：Pillow、NumPy，编码检查需OpenCV。渲染使用Node、Playwright、Chromium兼容浏览器和支持libx264/AAC的FFmpeg。中文字体采用Microsoft YaHei，并提供PingFang SC、Noto Sans CJK SC后备。

从本目录执行，按实际安装位置传入工具路径：

```text
python build_preview.py --ffmpeg <FFmpeg可执行文件>
node render_preview.cjs <Playwright模块目录> <浏览器可执行文件> <FFmpeg可执行文件>
python inspect_preview.py
```

渲染命令末尾追加`stills`只输出关键帧和页面检查。视频、音轨与编码记录写入被Git忽略的`renders/`，源文件和关键帧正常保留。操作音包含必修批量加购、选修点击与飞入、费用提示、支付面板、数字转移和倒数、支付成功及熄屏；不含配乐与主播对白。
